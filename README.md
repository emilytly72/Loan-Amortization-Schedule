# Loan-Amortization-Schedule
Purpose: Calculates a loan's monthly payment based on the loan amount, number of years, and annual interest rate.
         Generates a month-by-month amortization schedule that shows much of each payment goes into interest and how much toward paying off the principal.
         It also displays the remaining loan balance each month. The program also calculates and displays the total amount paid over the life of the loan.
