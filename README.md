# Loan-Amortization-Schedule
ABOUT:

A Java project that calculates loan payments and creates a monthly loan amortization schedule.
The program asks the user to input the loan amount, the annual interest rate, and the repayment period in number of years.
The program then calculates the monthly payment and displays how much goes toward interest and principal each month, as well as the remaining loan balance.

FEATURES:
- Calculates and displays monthly payment
- Calculates and displays interest and principal for each monthly payment
- Calculates and displays the remaining loan balance each month
- Calculates and displays the total amount paid over the loan period

REQUIREMENTS:

Java Development Kit (JDK)

Eclipse IDE (optional)

HOW TO RUN:

Eclipse
1. Download the repository by clicking Code -> Download ZIP
2. Extract the ZIP file
3. Open Eclipse
4. Select File -> Import -> Existing Projects into Workspace
5. Select the extracted folder and click Finish
6. Open src -> loanamortizationschedule -> LoanAmortizationSchedule.java
7. Right-click the file and select Run As -> Java Application
8. Enter the requested loan information in the console

Bash
1. Open Command Prompt in the Loan_Amortization_Schedule folder
2. Type javac -d out src/loanamortizationschedule/LoanAmortizationSchedule.java
3. Enter
4. Type java -cp out loanamortizationschedule.LoanAmortizationSchedule
5. Enter
6. Enter the requested loan information in the console
